# 📱 Mini Chat App (SwiftUI)

A lightweight **SwiftUI chat app** that simulates real-time messaging **without any backend**.
Built to practice **state management, async behavior, and chat UX patterns**.

---

## 🚀 Features

* Chat UI with sent & received messages
* Local message persistence
* Simulated delayed responses
* Typing indicator
* Message retry on failure

---

## 🧠 What It Demonstrates

* SwiftUI state management
* Async behavior simulation
* Clean UI & UX flow
* Lightweight MVVM structure

---

## 🛠️ Tech Stack

* Swift
* SwiftUI
* MVVM
* iOS
